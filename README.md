# 📝 Task Manager API

![Java](https://img.shields.io/badge/Java-21-orange)
![Spring Boot](https://img.shields.io/badge/Spring_Boot-3.x-green)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-15-blue)
![Docker](https://img.shields.io/badge/Docker-Enabled-2496ED)

Uma API RESTful completa para gerenciamento de tarefas, desenvolvida para demonstrar conhecimentos em **Microsserviços**, **Containerização** e **Boas Práticas de Infraestrutura**.

O projeto utiliza **Docker Multi-Stage Build**, o que significa que você não precisa ter o Java ou Maven instalados na sua máquina para rodar a aplicação. O Docker cuida de tudo (compilação e execução).

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java 21
* **Framework:** Spring Boot 3
* **Banco de Dados:** PostgreSQL
* **Infraestrutura:** Docker & Docker Compose
* **Segurança:** Variáveis de Ambiente (.env)

---
